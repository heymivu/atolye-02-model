Gün eşlemesi düzeltildi (`weekday()` Pazartesi=0 döndürüyordu) ve Pazartesi kayıtları artık Pazar'a yazılıyor.
Tutarlar binlik noktası atılarak tam sayı kuruşa çevriliyor, böylece "1.234,50" çökmüyor ve float yuvarlama hatası olmuyor.
Çıktı binlik ayraçlı, iki haneli Türkçe biçimde veriliyor (eksi toplamlar da dahil) ve günler Salı'dan Pazar'a sıralanıyor.

```python
# -*- coding: utf-8 -*-
"""Köşe Kahve kasa özeti.

haftalik_ozet(kayitlar) bir haftanın kasa kayıtlarını gün gün toplar.
kayitlar: [{"tarih": "2026-11-03", "tur": "satis" | "iade", "tutar": "1.234,50"}, ...]
  tutar Türkçe biçimde yazılır (binlik ayraç nokta, ondalık virgül) ve her zaman pozitiftir.

Kurallar:
1. Satış toplama eklenir, iade düşülür. İade, iadenin yapıldığı günün toplamından düşülür.
2. Pazartesileri kapalıyız. Pazartesi tarihli bir kayıt, önceki Pazar'ın geç girilmiş kaydıdır ve Pazar'a yazılır.
3. Tutarlar kuruşu kuruşuna toplanır; yuvarlama hatası olmaz.
4. Dönüş: {"gunler": {"Salı": "1.234,50", ...}, "toplam": "9.876,00"}
   - gunler yalnız kaydı olan günleri içerir; gün adları Türkçe (Salı, Çarşamba, Perşembe, Cuma, Cumartesi, Pazar).
   - Para Türkçe biçimde: binlik ayraç nokta, ondalık virgül, her zaman iki hane ("0,50", "12.000,00").
"""
from datetime import date
from decimal import Decimal, InvalidOperation

# date.weekday(): Pazartesi=0 ... Pazar=6
GUNLER = ["Pazartesi", "Salı", "Çarşamba", "Perşembe", "Cuma", "Cumartesi", "Pazar"]

# Çıktıdaki gün sırası (Pazartesi kapalı, kayıtları Pazar'a gider)
SIRA = ["Salı", "Çarşamba", "Perşembe", "Cuma", "Cumartesi", "Pazar"]


def _kurus(s):
    """Türkçe biçimli tutarı ("1.234,50") tam sayı kuruşa çevirir."""
    temiz = str(s).strip().replace(".", "").replace(",", ".")
    try:
        d = Decimal(temiz)
    except InvalidOperation:
        raise ValueError("Geçersiz tutar: %r" % (s,))
    k = d * 100
    if k != k.to_integral_value():
        raise ValueError("Tutar kuruştan küçük hane içeriyor: %r" % (s,))
    return int(k)


def _bicim(kurus):
    """Tam sayı kuruşu Türkçe para biçimine çevirir ("12.000,00")."""
    isaret = "-" if kurus < 0 else ""
    kurus = abs(kurus)
    lira, kr = divmod(kurus, 100)
    lira_metin = "{:,}".format(lira).replace(",", ".")
    return "%s%s,%02d" % (isaret, lira_metin, kr)


def haftalik_ozet(kayitlar):
    toplamlar = {}
    for k in kayitlar:
        g = GUNLER[date.fromisoformat(k["tarih"]).weekday()]
        if g == "Pazartesi":
            g = "Pazar"
        t = _kurus(k["tutar"])
        if k["tur"] == "iade":
            t = -t
        toplamlar[g] = toplamlar.get(g, 0) + t
    toplam = sum(toplamlar.values())
    gunler = {g: _bicim(toplamlar[g]) for g in SIRA if g in toplamlar}
    return {"gunler": gunler, "toplam": _bicim(toplam)}
```
