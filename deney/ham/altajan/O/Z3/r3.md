Gün adı hatalıydı (`weekday()` Pazartesi=0 döner, liste Pazar'dan başlıyordu); düzelttim ve Pazartesi kayıtlarını önceki Pazar'a yazdım.
Tutarlar binlik noktası atılıp `Decimal` ile okunuyor; `float` yerine kuruş hassasiyetinde toplanıyor, yuvarlama hatası yok.
Çıktı binlik nokta + ondalık virgül + iki hane biçiminde; günler hafta sırasıyla (Salı → Pazar) ve yalnız kaydı olanlar.

```python
# -*- coding: utf-8 -*-
"""Köşe Kahve kasa özeti.

haftalik_ozet(kayitlar) bir haftanın kasa kayıtlarını gün gün toplar.
kayitlar: [{"tarih": "2026-11-03", "tur": "satis" | "iade", "tutar": "1.234,50"}, ...]
  tutar Türkçe biçimde yazılır (binlik ayraç nokta, ondalık virgül) ve her zaman pozitiftir.

Kurallar:
1. Satış toplama eklenir, iade düşülür. İade, iadenin yapıldığı günün toplamından düşülür.
2. Pazartesileri kapalıyız. Pazartesi tarihli bir kayıt, önceki Pazar'ın geç girilmiş kaydıdır ve Pazar'a yazılır.
3. Tutarlar kuruşu kuruşuna toplanır; yuvarlama hatası olmaz.
4. Dönüş: {"gunler": {"Salı": "1.234,50", ...}, "toplam": "9.876,00"}
   - gunler yalnız kaydı olan günleri içerir; gün adları Türkçe (Salı, Çarşamba, Perşembe, Cuma, Cumartesi, Pazar).
   - Para Türkçe biçimde: binlik ayraç nokta, ondalık virgül, her zaman iki hane ("0,50", "12.000,00").
"""
from datetime import date, timedelta
from decimal import Decimal

# date.weekday(): Pazartesi=0 ... Pazar=6
GUNLER = ["Pazartesi", "Salı", "Çarşamba", "Perşembe", "Cuma", "Cumartesi", "Pazar"]
# Çıktıda hafta sırası (Pazartesi kapalı, kayıtları Pazar'a gider)
SIRA = ["Salı", "Çarşamba", "Perşembe", "Cuma", "Cumartesi", "Pazar"]

KURUS = Decimal("0.01")


def _tl(s):
    """'1.234,50' -> Decimal('1234.50')"""
    s = str(s).strip().replace(".", "").replace(",", ".")
    return Decimal(s).quantize(KURUS)


def _bicim(x):
    """Decimal('1234.5') -> '1.234,50'"""
    x = Decimal(x).quantize(KURUS)
    s = "{:,.2f}".format(x)  # '1,234.50'
    return s.replace(",", "_").replace(".", ",").replace("_", ".")


def _gun(tarih):
    d = date.fromisoformat(tarih)
    if d.weekday() == 0:  # Pazartesi -> önceki Pazar
        d = d - timedelta(days=1)
    return GUNLER[d.weekday()]


def haftalik_ozet(kayitlar):
    gunler = {}
    for k in kayitlar:
        g = _gun(k["tarih"])
        t = _tl(k["tutar"])
        if k["tur"] == "iade":
            t = -t
        gunler[g] = gunler.get(g, Decimal("0")) + t
    toplam = sum(gunler.values(), Decimal("0"))
    sirali = {g: _bicim(gunler[g]) for g in SIRA if g in gunler}
    return {"gunler": sirali, "toplam": _bicim(toplam)}
```
