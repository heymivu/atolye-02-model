Üç hata düzeltildi: GUNLER dizisi weekday() ile hizasızdı (Pazartesi "Pazar", Pazar "Cumartesi" çıkıyordu), Pazartesi kayıtları artık önceki Pazar'a yazılıyor.
Binlik ayraçlı tutarlarda _tl noktayı ondalık sanıp çöküyordu; ayrıştırma düzeltildi.
Toplamlar float yerine Decimal ile kuruşu kuruşuna yapılıyor, biçim binlik noktalı ("12.000,00").

```python
# -*- coding: utf-8 -*-
"""Köşe Kahve kasa özeti.

haftalik_ozet(kayitlar) bir haftanın kasa kayıtlarını gün gün toplar.
kayitlar: [{"tarih": "2026-11-03", "tur": "satis" | "iade", "tutar": "1.234,50"}, ...]
  tutar Türkçe biçimde yazılır (binlik ayraç nokta, ondalık virgül) ve her zaman pozitiftir.

Kurallar:
1. Satış toplama eklenir, iade düşülür. İade, iadenin yapıldığı günün toplamından düşülür.
2. Pazartesileri kapalıyız. Pazartesi tarihli bir kayıt, önceki Pazar'ın geç girilmiş kaydıdır ve Pazar'a yazılır.
3. Tutarlar kuruşu kuruşuna toplanır; yuvarlama hatası olmaz.
4. Dönüş: {"gunler": {"Salı": "1.234,50", ...}, "toplam": "9.876,00"}
   - gunler yalnız kaydı olan günleri içerir; gün adları Türkçe (Salı, Çarşamba, Perşembe, Cuma, Cumartesi, Pazar).
   - Para Türkçe biçimde: binlik ayraç nokta, ondalık virgül, her zaman iki hane ("0,50", "12.000,00").
"""
from datetime import date
from decimal import Decimal

# date.weekday() sırasıyla: Pazartesi=0 ... Pazar=6
GUNLER = ["Pazartesi", "Salı", "Çarşamba", "Perşembe", "Cuma", "Cumartesi", "Pazar"]
SIRA = ["Salı", "Çarşamba", "Perşembe", "Cuma", "Cumartesi", "Pazar"]
KURUS = Decimal("0.01")


def _tl(s):
    return Decimal(s.replace(".", "").replace(",", "."))


def _bicim(x):
    x = x.quantize(KURUS)
    isaret = "-" if x < 0 else ""
    tam, kurus = divmod(int(abs(x) * 100), 100)
    return "%s%s,%02d" % (isaret, f"{tam:,}".replace(",", "."), kurus)


def haftalik_ozet(kayitlar):
    gunler = {}
    for k in kayitlar:
        g = GUNLER[date.fromisoformat(k["tarih"]).weekday()]
        if g == "Pazartesi":
            g = "Pazar"
        t = _tl(k["tutar"])
        if k["tur"] == "iade":
            t = -t
        gunler[g] = gunler.get(g, Decimal("0")) + t
    toplam = sum(gunler.values(), Decimal("0"))
    return {
        "gunler": {g: _bicim(gunler[g]) for g in SIRA if g in gunler},
        "toplam": _bicim(toplam),
    }
```
