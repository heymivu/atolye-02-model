**Aralık latte maliyeti ve menü fiyatı**

**1. Malzeme maliyeti (Aralık fiyatları, latte başına)**

- Kahve: 18 g × 1.290 TL/kg = 0,018 × 1.290 = **23,22 TL** (Kasım'daki 1.150 TL değil, 1 Aralık'tan geçerli 1.290 TL kullanıldı)

- Bardak + kapak: **7,40 TL**
- Toplam malzeme: 23,22 + 10,89 + 7,40 = **41,51 TL**

**2. Hedef koşulunun kurulması**

- P = menü fiyatı (KDV dahil), N = KDV hariç satış = P / 1,10

- Brüt kâr = N − 0,0198 N − 41,51
- Hedef: brüt kâr ≥ %65 × N = 0,65 N

Bu eşitsizlik:
N − 0,0198 N − 41,51 ≥ 0,65 N
0,3302 N ≥ 41,51
N ≥ 125,71 TL

P = 1,10 × N ≥ 1,10 × 125,71 = **138,28 TL**
