## Aralık latte menü fiyatı hesabı

**1. Malzeme maliyeti (Aralık fiyatlarıyla, KDV dahil alış)**

- Kahve: çift shot = 18 g = 0,018 kg. Aralık kilo fiyatı 1.290 TL.
  0,018 × 1.290 = **23,22 TL**
- Süt: koli 540 TL / 12 litre = 45 TL/L. Bardağa 220 ml girer; dökülen ve pitcher'da kalan kayıp için %10 fazla çekilir.
  220 ml × 1,10 = 242 ml = 0,242 L. 0,242 × 45 = **10,89 TL**
- Kağıt bardak + kapak: **7,40 TL**

Toplam malzeme: 23,22 + 10,89 + 7,40 = **41,51 TL**

**2. Satış tarafı (N = KDV hariç satış tutarı, P = menü fiyatı KDV dahil)**

- N = P / 1,10
- Kart komisyonu = %1,8 × P (KDV dahil tutar üzerinden) = 0,018 × 1,10 N = 0,0198 N
- Brüt kâr = N − 0,0198 N − 41,51
- Hedef: brüt kâr ≥ %65 × N

**3. Eşitsizlik**

N − 0,0198 N − 41,51 ≥ 0,65 N
0,3302 N ≥ 41,51
N ≥ 125,71 TL
P ≥ 1,10 × 125,71 = 138,28 TL

**4. 5 TL katına yuvarlama**

138,28 TL'nin üstündeki ilk 5 katı: **140 TL**.

**5. Kontrol**

- P = 135 TL: N = 122,73; komisyon = 2,43; brüt kâr = 122,73 − 2,43 − 41,51 = 78,79; oran = 78,79 / 122,73 = %64,2. Hedefin altında, tutmaz.
- P = 140 TL: N = 127,27; komisyon = 2,52; brüt kâr = 127,27 − 2,52 − 41,51 = 83,24; oran = 83,24 / 127,27 = %65,4. Hedef tutar.
