Düzeltmeler:
- Gün adı eşlemesi kaymıştı (`weekday()` Pazartesi=0 verirken liste Pazar'dan başlıyordu); artık gün adı doğru bulunuyor ve Pazartesi tarihli kayıtlar önceki Pazar'a yazılıyor.
- Tutar ayrıştırması Türkçe biçime göre yapılıyor ("1.234,50" artık çökmüyor) ve toplamlar float yerine tam sayı kuruşla tutuluyor, yani yuvarlama hatası yok.
- Çıktı Türkçe biçimde (binlik nokta, ondalık virgül, her zaman iki hane; negatif ve sıfır dahil) üretiliyor, günler Salı'dan Pazar'a sıralı.

```python
# -*- coding: utf-8 -*-
"""Köşe Kahve kasa özeti.

haftalik_ozet(kayitlar) bir haftanın kasa kayıtlarını gün gün toplar.
kayitlar: [{"tarih": "2026-11-03", "tur": "satis" | "iade", "tutar": "1.234,50"}, ...]
  tutar Türkçe biçimde yazılır (binlik ayraç nokta, ondalık virgül) ve her zaman pozitiftir.

Kurallar:
1. Satış toplama eklenir, iade düşülür. İade, iadenin yapıldığı günün toplamından düşülür.
2. Pazartesileri kapalıyız. Pazartesi tarihli bir kayıt, önceki Pazar'ın geç girilmiş kaydıdır ve Pazar'a yazılır.
3. Tutarlar kuruşu kuruşuna toplanır; yuvarlama hatası olmaz.
4. Dönüş: {"gunler": {"Salı": "1.234,50", ...}, "toplam": "9.876,00"}
   - gunler yalnız kaydı olan günleri içerir; gün adları Türkçe (Salı, Çarşamba, Perşembe, Cuma, Cumartesi, Pazar).
   - Para Türkçe biçimde: binlik ayraç nokta, ondalık virgül, her zaman iki hane ("0,50", "12.000,00").
"""
from datetime import date

# date.weekday(): Pazartesi=0 ... Pazar=6
GUNLER = ["Pazartesi", "Salı", "Çarşamba", "Perşembe", "Cuma", "Cumartesi", "Pazar"]

# Çıktıda kullanılacak gün sırası (Pazartesi kapalı, kayıtları Pazar'a yazılır)
SIRA = ["Salı", "Çarşamba", "Perşembe", "Cuma", "Cumartesi", "Pazar"]


def _kurus(s):
    """'1.234,50' -> 123450 (tam sayı kuruş)."""
    s = str(s).strip().replace(" ", "")
    if "," in s:
        tam, kes = s.split(",", 1)
    else:
        tam, kes = s, ""
    tam = tam.replace(".", "") or "0"
    kes = (kes + "00")[:2]
    return int(tam) * 100 + int(kes)


def _bicim(kurus):
    """123450 -> '1.234,50' (negatifte başa '-')."""
    isaret = "-" if kurus < 0 else ""
    lira, kr = divmod(abs(kurus), 100)
    lira_s = "{:,}".format(lira).replace(",", ".")
    return "%s%s,%02d" % (isaret, lira_s, kr)


def _gun_adi(tarih):
    ad = GUNLER[date.fromisoformat(tarih).weekday()]
    # Pazartesi kapalı: o günün kaydı önceki Pazar'a aittir.
    return "Pazar" if ad == "Pazartesi" else ad


def haftalik_ozet(kayitlar):
    gunler = {}
    for k in kayitlar:
        g = _gun_adi(k["tarih"])
        t = _kurus(k["tutar"])
        if k["tur"] == "iade":
            t = -t
        gunler[g] = gunler.get(g, 0) + t
    toplam = sum(gunler.values())
    return {
        "gunler": {g: _bicim(gunler[g]) for g in SIRA if g in gunler},
        "toplam": _bicim(toplam),
    }
```
